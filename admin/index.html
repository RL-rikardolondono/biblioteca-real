Configuración inicial (solo una vez)

Para que el panel pueda publicar en la web, GitHub necesita una llave de acceso. Se pega una sola vez: queda guardada de forma segura en el servidor y nadie tendrá que volver a verla.

  1. Inicie sesión en GitHub y abra esta página.
  2. En Token name escriba: Panel Biblioteca Real. En Expiration elija No expiration.
  3. En Repository access elija Only select repositories y marque solo biblioteca-real.
  4. En Permissions → Repository permissions, ponga Contents en Read and write. Nada más.
  5. Pulse Generate token, copie la llave (empieza por github_pat_) y péguela aquí abajo.
